# Como contribuir

1. Atualize sua cópia da branch main e crie uma branch para a alteração.
2. Faça a alteração e execute os testes quando modificar o código.
3. Use uma mensagem de commit que descreva o que mudou, como `Corrigir bloqueio de pedidos para livro emprestado`.
4. Abra um pull request com um resumo da alteração e dos testes realizados.
5. Revise com o outro integrante antes do merge.

Use sua própria conta nos commits. Não inclua senhas ou arquivos com credenciais. Os requisitos e o cronograma estão no [README](README.md).
