# Código-fonte

main/java/br/edu/sebo contém as camadas Java e a configuração JDBC. test/java/br/edu/sebo contém os testes JUnit.

Implementados: cadastro/consulta de usuários, CRUD de livros, solicitações, aceite/recusa, devolução, troca e histórico (RF01–RF06). O modelo inclui composição Usuario–Livro e finalização polimórfica nas subclasses LivroTroca e LivroEmprestimo. Veja [guia do código](../docs/guia-do-codigo.md), [execução](../docs/execucao.md) e [conferência da entrega](../docs/conferencia-final.md).
