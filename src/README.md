# Código-fonte

Diretório reservado para a implementação Java, ainda pendente.

- `model/`: Usuario, Livro abstrato, LivroTroca, LivroEmprestimo e Solicitacao.
- `dao/`: acesso ao MySQL por JDBC.
- `service/`: regras de negócio e coordenação transacional.
- `controller/`: ponto de entrada e interação com o usuário.

Os arquivos .gitkeep apenas mantêm as pastas no Git. Nenhuma classe ou funcionalidade foi implementada nesta etapa. A organização poderá ser ajustada ao definir pacotes e ferramenta de build, preservando as responsabilidades planejadas.
